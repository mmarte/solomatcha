# SoloMatcha

Static site generated by `build.py`. Cloudflare Workers serves the `public/` folder.

## Everyday workflow
- Publish a guide: put a `.md` file in `content/guides/` (see any existing file for the front matter), remove `draft: true`, commit to main. Cloudflare rebuilds in about a minute.
- Schedule a guide: set `date:` in the future. It appears on that day after the next build (see "Scheduled dates" below).
- Preview locally: `pip install -r requirements.txt && python3 build.py --drafts && cd public && python3 -m http.server`.
- Run checks: `pip install pytest && python3 -m pytest tests`.

## Where the money goes
- **Affiliate links**: add an entry to `affiliates.json` (`"matcha-source": {"url": "...", "merchant": "..."}`), then in a guide write `[Buy here](aff:matcha-source)`. The build adds `rel="sponsored nofollow"`, a link arrow, and a disclosure box at the top of that guide. Unknown keys fail the build.
- **Ad network / analytics code**: paste the snippet(s) the network gives you into `head_snippets` (or `body_end_snippets`) in `site.json`. They load on every page.
- **ads.txt**: when an ad network approves you, add `static/_redirects` with `/ads.txt  <their ads.txt URL>  301` (Raptive documents this) or put the file in `static/ads.txt`.
- **Before ads go live**: write `content/pages/privacy.md` (currently a draft placeholder, remove `draft: true`) and add a cookie-consent tool if your network requires one for US/EU visitors.

## Article pipeline
`content/topics.csv` is the editorial queue. `pipeline/generate.py` drafts the next `planned` topic (never reviews) into `content/guides/` with `draft: true`, then the "Draft next article" GitHub Action opens a pull request twice a week. You read it, add first-hand detail, fix every `TODO(`, check numbers against `pipeline/facts.md` sources, remove `draft: true`, merge. Add topics by adding rows to the CSV.

## Gates (the build fails on any of these for a published guide)
`TODO(` markers, health-claim phrases (`site.json` > `health_claim_patterns`), unknown `aff:` keys, missing front matter, unknown category, duplicate slugs.

## Setup checklist
1. Cloudflare Worker > Settings > Build: build command `pip install -r requirements.txt && python3 build.py`, deploy command `npx wrangler deploy`.
2. GitHub repo > Settings > Secrets > Actions: add `ANTHROPIC_API_KEY`.
3. GitHub repo > Settings > Actions > General: allow Actions to create pull requests.

## Scheduled dates
The site only rebuilds when you push. A guide dated in the future shows up on the first build after that date. To make that automatic, add a Cloudflare deploy hook called daily by a GitHub scheduled workflow.
